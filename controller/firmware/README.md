# Requirements

- [probe-rs](https://probe.rs/)
- [Rust](https://rust-lang.org/)

# Running

1. Connect the Pi Debug Probe and Pico 2 to your computer.
1. Run `cargo run`. This uploads the firmware to the Pico 2 via the Debug Probe, runs it, and prints subsequent log messages. You don't need to run this again unless you change the firmware or want to see log messages.
